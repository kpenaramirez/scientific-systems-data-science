# Scientific Systems Data Analysis

A curated collection of Jupyter notebooks demonstrating applied data science techniques on real engineering and scientific systems. The work spans thermal modeling, system monitoring, and predictive analysis of physical processes. Each notebook showcases practical analytical workflows used in large-scale scientific instrumentation environments.

## Rubin Observatory System Performance Analyses
Analyses of telemetry from the NSF-DOE Vera C. Rubin Observatory (EFD, ConsDB) supporting commissioning, operations, verification and system optimization.


## What this repository demonstrates
- Multivariate data analysis
- Time-series modeling and diagnostics
- Thermal and physical system simulation
- Predictive modeling and threshold analysis
- Automated monitoring and alerting logic
- Data visualization for engineering decision-making

## Contents

### Thermal-Gradient Modeling of Large-Scale Structures.ipynb
Numerical modeling and visualization of temperature gradients across a large mechanical structure. Demonstrates simulation, interpolation, and spatial analysis techniques.

### Thermal Performance Analysis of High-Precision Mechanical Systems.ipynb
Time-series thermal analysis and anomaly detection for a precision shutter mechanism.

### Automated Monitoring & Alerting Pipeline for Engineering Systems.ipynb
Watcher Alarm Analysis during the ComCam On-Sky Campaign.

### Predictive Modeling of System Closure Conditions.ipynb
Predictive modeling and threshold analysis for determining safe closure conditions.

### Modeling of Venting Dynamics in Controlled Environments.ipynb
Modeling of venting behavior under varying environmental and operational scenarios.

## How to use this repository
Runs on the Rubin Science Platform/USDF with the LSST Science Pipelines; requires EFD and ConsDB access.

Recommended environment:
- Python 3.9+
- JupyterLab or Jupyter Notebook
- NumPy, SciPy, Pandas, Matplotlib, Seaborn, scikit-learn
